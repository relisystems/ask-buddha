*ask-buddha: a skill for Claude*
Ask Claude what the Buddha would think about anything. You get what the Pali texts say (with links), what modern knowledge adds, and where that reading stops.

*Install it on your phone (once)*
1. Save the attached file *ask-buddha.zip*. Don't tap it to open it.
2. Open Chrome or Safari (not the Claude app), go to claude.ai and sign in.
3. Switch to desktop view:
Chrome: ⋮ > Desktop site
Safari: aA > Request Desktop Website
4. In the address bar, type claude.ai/settings/capabilities and turn on "Create and edit files" (older name: "Code execution and file creation"). Can't find it? Skip this step: if step 5 works, it's already on.
5. In the address bar, type claude.ai/customize/skills. Tap +, then Create skill > Upload a skill, and choose *ask-buddha.zip*.

*Use it*
In the Claude app, start your question with:
Use the ask-buddha skill: what would the Buddha say about anger?
