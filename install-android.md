# Install Ask Buddha on Android

Ask Claude what the Buddha would think about anything. You get what the Pali texts say (with links), what modern knowledge adds, and where that reading stops.

You do this once. It takes about five minutes.

## 1. Download

In **Chrome**, open this link:

**[ask-buddha-plugin.zip](https://github.com/relisystems/ask-buddha/releases/latest/download/ask-buddha-plugin.zip)**

The file saves to **Downloads**. Don't open it.

## 2. Open Claude in Chrome

1. Go to **claude.ai** and sign in.
2. Tap **⋮** (top right) and tick **Desktop site**.

## 3. Turn on files

Go to **claude.ai/settings/capabilities** and turn on **Create and edit files** (or **Code execution and file creation**).

Not there? Skip this step.

Menu: **☰** (top left) > your name > **Settings** > **Capabilities**

## 4. Upload

Go to **claude.ai/customize/plugins**, then tap **+** > **Upload plugin** > **Downloads** > **ask-buddha-plugin.zip**.

Menu: **☰** (top left) > **Plugins** (or **Customize**) > **+** > **Upload plugin**

## 5. Use it

In the Claude app, start your question with:

> Use the ask-buddha skill: what would the Buddha say about anger?
