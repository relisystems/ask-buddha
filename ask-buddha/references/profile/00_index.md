# The Buddha of the Pali Tipiṭaka: a psychological profile (version 2): index

Core reference for the **ask-buddha** skill. Version 2, written 23 November 2026 from a reading of the whole Pali canon; it revises version 1 (22 November 2026, a random sample of 48 texts). The method record is in `references/buddha_profile_sources.md`; the evidence, tallies, and change notes stay with the author.

Read section 1 first for the evidence base, the attestation labels, and the conventions; then the sections a question needs. Section 13 holds the rules for the ask-buddha skill.
